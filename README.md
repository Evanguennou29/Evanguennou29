# Bonjour 👋

Je m’intéresse à l’analyse de données et au machine learning avec Python. Ici, je partage des projets reproductibles, avec une méthode expliquée et des résultats présentés avec leurs limites.

## Projet en vedette

### [PalmerMorphoBench — classification de manchots](https://github.com/Evanguennou29/PalmerMorphoBench-MachineLearning)

Un benchmark qui compare une baseline et trois modèles pour prédire l’espèce de manchots à partir de quatre mesures morphométriques. Le projet comprend un [notebook d’exploration](https://github.com/Evanguennou29/PalmerMorphoBench-MachineLearning/blob/main/notebooks/comparaison_modeles.ipynb), des pipelines de préparation, une validation croisée stratifiée et des [résultats détaillés](https://github.com/Evanguennou29/PalmerMorphoBench-MachineLearning/blob/main/results/metrics.json).

**Résultat :** le modèle sélectionné atteint un F1 macro moyen de **0,976** en validation croisée sur les données d’entraînement. Le [README du projet](https://github.com/Evanguennou29/PalmerMorphoBench-MachineLearning#readme) décrit le protocole et les limites de cette estimation.
